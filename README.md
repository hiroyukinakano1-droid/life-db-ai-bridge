# life-db-ai-bridge

AIチャット（Claude）から、Google Sheetsで管理する「人生DB（キャリア・実績・選考管理台帳）」へ、
確認テーブル＋ワンクリックリンクで安全に書き込みを行うための橋渡しスクリプト集です。

## 背景・課題

転職活動において、応募企業・選考状況・実績エピソードなどの情報を一元管理する
Google Sheets製DBを運用していましたが、AIチャット側から直接スプレッドシートに
書き込む標準手段がありませんでした。

## 解決策

Google Apps Script（GAS）をWebアプリとしてデプロイし、AIチャット側から
`fetch`（GET）でパラメータを渡すだけでシートに1行追記できる「橋渡しAPI」を構築しました。

- AI側は、追記したい内容を確認用のテーブルとして提示
- ユーザーが内容を確認し、生成されたワンクリックリンクをクリックするだけで反映
- トークン認証による簡易的な不正アクセス防止
- 存在しないシート名が指定された場合の自動作成、JSON解析失敗時のフォールバック処理も実装

## 構成ファイル

- `addRowWebApp.js` : GAS側のWebアプリ本体（doGet関数）。トークン認証、シート自動作成、
  データ整形（折り返し・フォントサイズ統一）を行う
- `sendDailyIdeas.js` : 毎朝、ユーザーのプロフィール・現在の目標・進行中プロジェクトの
  文脈をプロンプトに埋め込み、Gemini APIで戦略提案を自動生成・配信するスクリプト
  （503エラー時の自動リトライ機構つき）

## 使用技術

Google Apps Script / Google Sheets API / Gemini API / Claude（AIチャット連携）

## 工夫した点

- AIチャット単体では実現できない「外部システムへの書き込み」を、GASを橋渡し役にする
  ことで実現（ネットワーク制限のある実行環境でも動作する設計）
- 誤操作防止のため、AIが即座に書き込むのではなく、必ず人間の目視確認とクリックを
  介するフロー（Human-in-the-loop）を徹底
- サーバー過負荷（503エラー）への自動リトライ、シート構造の動的解析など、実運用で
  発生した問題を都度解決しながら改善

※機密情報（APIキー・スプレッドシートID・アクセストークン）は、公開にあたりすべて
プレースホルダーに置き換えています。
